# Source of the FNF MIDI files

The nine `.mid` files in this folder (`bopeebo`, `dad_battle`, `eggnog`, `high`, `milf`, `roses`, `satin_panties`, `south`, `thorns`) come from the GitHub repository **MIDI-FNF-Full-And-Most-Accurate** by FujiwaraZachWatterson: https://github.com/FujiwaraZachWatterson/MIDI-FNF-Full-And-Most-Accurate

That repository collects MIDI transcriptions of Friday Night Funkin' songs (and mods), made for the author's own videos. The files here are the ones listed in `songs.list`; `tools/midi2beatmap` converts them into the charts in `assets/beatmaps/fnf/` (see `docs/SONGS.md`).
