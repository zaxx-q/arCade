arCade - cara bermain
========================

Windows: ekstrak (unzip) foldernya di mana saja (jangan di dalam folder yang dilindungi), lalu klik dua kali arCade.exe.
Linux:   tar xzf arCade-*.tar.gz && cd arCade-* && ./arCade
         (butuh library desktop yang umum: OpenGL dan X11, yang ada di instalasi desktop biasa)

Kontrol ditampilkan di menu untuk game yang sedang dipilih.
  Menu:   Up/Down atau mouse: memilih   Enter atau klik: main   L: leaderboard   N: ganti nama   Esc: keluar
  Di dalam game: Esc kembali ke menu.
  Background menu: klik kiri mouse menggambar pasir, klik kanan menggambar air (di separuh kanan layar).

Skor disimpan di scores.txt di sebelah programnya. Hapus file itu untuk mereset leaderboard.
Progres Gritty Golf disimpan di gritty_save_<nama>.dat di folder yang sama (satu file per pemain). Hapus file itu untuk mengulang dari level pertama.

Command line (opsional):
  arCade --version        tampilkan versi
  arCade --list           tampilkan daftar game
  arCade --help           semua opsi

Windows mungkin menampilkan peringatan SmartScreen untuk program yang tidak ditandatangani: pilih "More info" -> "Run anyway".
