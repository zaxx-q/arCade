arCade - cara bermain
========================

arCade hanya satu file (font, suara, tekstur, dan lagu sudah ada di dalamnya).
Windows: taruh arCade-*.exe di folder mana saja (jangan di dalam folder yang dilindungi), lalu klik dua kali.
Linux:   chmod +x arCade-*-linux-x86_64 && ./arCade-*-linux-x86_64
         (butuh library desktop yang umum: OpenGL dan X11, yang ada di instalasi desktop biasa)

Kontrol ditampilkan di menu untuk game yang sedang dipilih.
  Menu:   Up/Down atau mouse: memilih   Enter atau klik: main   L: leaderboard   N: ganti nama   Esc: keluar
  Di dalam game: Esc kembali ke menu.
  Background menu: kota neon (Synthwave City) yang terbang sendiri. Klik di latar belakang untuk menyembunyikan
                   menu dan memainkan kotanya (WASD terbang, seret mouse menoleh, M bisukan lagu); Esc menampilkan
                   menu lagi. B atau tombol kecil di kanan atas menukar ke sandbox: klik kiri menggambar pasir,
                   klik kanan menggambar air.

Skor disimpan di scores.txt di sebelah programnya. Hapus file itu untuk mereset leaderboard.
Beat Dodge & Catch punya papan skor sendiri untuk setiap mode, lagu, dan kesulitan: di leaderboard, pilih game itu dengan Left/Right lalu ganti papan dengan Up/Down.
Leaderboard online menyala secara bawaan. Saat pertama dibuka ada layar pemberitahuan yang menjelaskan apa yang dikirim: tekan Enter untuk membiarkannya menyala, N atau Esc untuk mematikannya.
Kalau menyala, L membuka leaderboard langsung di tab Online (Tab: pindah ke skor lokal, R: segarkan, O: matikan skor online). Pilihanmu disimpan di online.cfg.
Linux: untuk memeriksa sertifikat server, game memakai file sertifikat CA sistem (paket ca-certificates). Kalau tidak ada, tab Online tampil offline dan tidak ada yang dikirim.
Progres Gritty Golf disimpan di gritty_save_<nama>.dat di folder yang sama (satu file per pemain). Hapus file itu untuk mengulang dari level pertama.

Command line (opsional):
  arCade --version        tampilkan versi
  arCade --list           tampilkan daftar game
  arCade --licenses       tampilkan teks lisensi dan atribusi pihak ketiga
  arCade --help           semua opsi

Windows mungkin menampilkan peringatan SmartScreen untuk program yang tidak ditandatangani: pilih "More info" -> "Run anyway".
